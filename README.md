# 글로벌 현장학습 예산 장부

호주 글로벌 현장학습에서 인솔교사가 쓰는 지출 장부입니다.
폰으로 **영수증을 찍고 금액을 적어 저장하면 → 구글 드라이브에 사진이 저장되고 구글 시트에 한 줄이 쌓입니다.**

- `index.html` — 화면(이 파일 하나로 동작, 외부 라이브러리 없음)
- `apps-script.gs` — 구글 쪽 받는 코드(선생님 구글 계정에 한 번 배포)

## 할 수 있는 것

- 예산표(구분 3개 · 항목 12개)에서 **구분 → 항목을 눌러 고르고** 지출 기록
- 호주 달러 · 싱가포르 달러(창이공항 환승) · 미국 달러 · 원화, 금액 칸에 `18.50*9` 같은 계산식 가능. 외화 금액은 그대로 남기고 원화는 **농협 비자 카드 청구 어림값**으로 계산 — 시장 환율 × (1 + 환율 가산 1.2%) + 카드 수수료 1.35%(비자 1.1% + 농협 0.25%), 합쳐 시장보다 약 2.6% 더
- 지출마다 **영수증 번호**(1, 2, 3 …)가 붙어 화면 · 구글 시트 · 엑셀 · 붙임 용지 · 사진 파일 이름에서 같은 번호로 찾을 수 있음
- 영수증 사진 여러 장(한 번에 6장까지, 긴 변 1600px 로 줄여서 올림)
- 인터넷이 끊기면 폰에 보관했다가 연결되면 올림(화면 위 "올리기 대기 N건")
- 구분 · 항목별 예산 / 사용 / 잔액, 예산을 넘으면 빨간 막대. 전체 예산은 **호주 달러로도** 보여 줌(지금 환율, 수수료 뺀 "더 쓸 수 있는 돈" 포함)
- **엑셀 내려받기** — `항목별 정리` · `지출 내역` 두 시트(가로 방향 · 너비 1쪽 인쇄 설정)
- **영수증 붙임 용지** — 학교 「신용카드 사용 후 제출 서식」(품의제목 · 카드번호 끝 4자리 · 품의자 + 영수증 칸) 모양으로, 지출을 저장할 때마다 한 장씩 PDF 가 드라이브에 자동으로 생김. 영수증 칸 위에 번호·사용일·금액 한 줄이 있어 엑셀에서 같은 번호로 찾을 수 있음
- **카드 고르기** — 지출마다 주 카드(8020) / 보조 카드(8012) 중 고름. 카드 번호와 품의자(기본 윤홍열)는 ⚙ 설정에서 바꿈
- 지출 취소(시트에서는 지우지 않고 '취소' 표시, 영수증 사진은 그대로)

## 처음 한 번: 구글에 연결하기 (약 5분)

1. <https://script.google.com> → **새 프로젝트**
2. 안에 있는 글자를 모두 지우고 `apps-script.gs` 내용을 통째로 붙여 넣기 → 저장(디스크 모양)
3. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행: **나**
   - 액세스 권한: **모든 사용자**
4. **배포** → 권한 요청 창이 뜨면 본인 계정 선택 → "고급" → "…(으)로 이동" → **허용**
5. 나온 **웹 앱 URL**(…`/exec` 로 끝남)을 복사
6. 장부 화면 ⚙ 설정 → **구글 드라이브 연결 주소**에 붙여 넣고 **연결 확인**
   - "연결되었습니다 (budget-v7)" 가 나오면 끝. [장부 시트 열기] · [영수증 폴더 열기] 단추가 생깁니다.
7. PC 에서 연결했다면 **폰으로 옮길 링크 복사** → 카톡 「나에게 보내기」로 보내 폰에서 열면 주소가 자동으로 들어갑니다.

코드를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전 "새 버전" → 배포** (주소는 그대로).

## 알아 둘 것

- 화면 맨 위 제목 아래 작은 글씨 "10월 16일 수정판 · 구글 코드 budget-v7"로 지금 쓰는 판을 알 수 있습니다. 화면을 고치면 `index.html` 의 `APP_VER` 날짜를 바꿉니다.

- 연결 주소는 화면 파일에 들어 있지 않고 **각 기기에만** 저장됩니다. 주소를 아는 사람만 장부에 쓸 수 있으니 남에게 보내지 마세요.
- 환율은 시장 기준값을 자동으로 받습니다. 실제 환전 · 카드 환율을 알면 ⚙ 설정에서 직접 적으세요. 이미 저장한 지출은 저장할 때 환율 그대로 남습니다.
- 결제는 모두 카드로 봅니다(결제 방법 칸 없음). 환율 가산 1.2% 와 카드 수수료 1.35% 는 **어림값**입니다(⚙ 설정에서 바꿈, [농협 비자 기본값으로] 단추). 실제는 매입일의 비자 환산율·농협 전신환매도율로 정해집니다. 결제 때 원화 결제(DCC)를 물으면 호주 달러를 고르세요. 실제 청구액은 카드 명세서로 확인해 엑셀의 `실제 카드 청구액(원)` 칸에 적으세요. 원화로 결제한 지출에는 여유분을 더하지 않습니다.
- 지출을 고치는 기능은 없습니다. 잘못 적었으면 **지출 취소** 뒤 다시 적습니다.
- 브라우저의 "인터넷 사용 기록 삭제"로 사이트 데이터를 지우면 **아직 올리지 못한** 기록과 사진이 사라집니다. "올리기 대기"가 0건인지 먼저 확인하세요.
